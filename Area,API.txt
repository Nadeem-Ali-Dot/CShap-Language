Rest API
----------
>> API is neither a technology nor a framework, It is a concept.
>> API is used to communicate having different environments [cross platform].
>> API generally return JSON [JavaScript Object Notation].
>> API is nothing it is just a Method.
------------------------------------------------------------
Rest:-
--------
>> It stands for 'Representational State Transfer'.
>> Rest is a Communication protocol under which our API will run.
